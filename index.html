✨ What Does ProceduralCurves Do?

Normally, animating in Unreal Engine 5 means opening a curve editor and clicking dozens — sometimes hundreds — of individual points called keyframes. Each keyframe is a moment in time that you place by hand. ProceduralCurves removes that chore entirely. Instead of clicking, you type a short formula or pick a waveform, and the plugin builds the curve for you automatically.

Think of it as the difference between drawing a wave by hand and simply telling the program "draw a wave." A sine wave keeps rising and falling smoothly forever. A square wave flips instantly between two values. A saw wave ramps up and resets. Noise adds natural, unpredictable variation. With ProceduralCurves, all of these are a single selection away.

The result is animation that never ends, never stutters, and never needs to be manually rebuilt. Because the curves are calculated from a formula rather than stored frame by frame, they play back identically whether your game runs at 30, 60, or 144 frames per second.

🧭 How to Use It in Your Project

Once the plugin is enabled, using ProceduralCurves takes only a few clicks. The whole idea is that you describe the motion you want, rather than drawing it.

Creating Your First Curve

  • Create a new curve asset in your project and choose the ProceduralCurves type.
  • Select a waveform from the built-in list — sine, square, saw or noise — as your starting layer.
  • Adjust the amplitude to control how far the curve travels, and the frequency to control how fast it repeats.
  • Add another layer on top if you want a more complex motion, for example a gentle sine combined with light noise.
  • Open the Details panel and watch the live plot update as you change values.
  • Connect the finished curve to the property you want to animate, such as a position, scale or rotation channel.
  • Press Play. The motion runs continuously with no keyframes to manage.

Writing a Formula

If you prefer words and numbers over waveforms, you can type a mathematical expression directly. Expressions can reference the current time, combine several functions, and use common operations like addition, multiplication and parentheses. The curve redraws as soon as the expression is valid, so you can experiment freely and see the result immediately in the live plot.

🔧 Why Formula-Based Curves Are Useful

Traditional keyframe animation stores a fixed list of positions. If you want a motion to run for ten minutes, you either need an enormous number of keys or you need to loop a short section, which often produces a visible jump. Formula-based curves have no such limitation. Because the value is calculated fresh at any moment in time, a procedural curve can run indefinitely without any repeating seam.

This also makes editing far faster. Changing a single number — the frequency, for example — instantly reshapes the entire curve, whereas with keyframes you would have to move every point individually. ProceduralCurves keeps that flexibility inside the familiar Unreal Engine 5 editor, so you do not have to leave your normal workflow.

The plugin is also built to be safe in demanding projects. Evaluation is thread-safe, meaning curves can be sampled from background tasks without causing crashes or unpredictable behaviour. Playback is frame-rate independent, so the same curve produces the same motion on a slow laptop and a high-end desktop.

❓ Frequently Asked Questions

Do I need to know how to code?

No. You can build complete curves using only the waveform presets and the numeric sliders. Typing a formula is optional and only needed if you want very specific control.

Will my existing keyframe curves still work?

Yes. ProceduralCurves adds a new way to define curves and does not replace or remove anything you already have in your project.

Can I use it for rotation as well as position?

Yes. Vector curves cover multi-axis values such as position and scale, and rotator curves handle rotation channels.
